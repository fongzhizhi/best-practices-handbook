## 《小资金进攻版交易手册 V2.1》

> **适用阶段**：本金 8.5 万 → 30 万（目标两年内完成）
> **核心理念**：中线逻辑优先，敢于在战略级别的机会上重仓，不为短期波动所动摇。
> **与 V2.0 的核心差异**：新增"第五看——估值水位滤网"防止买在顶部；新增时间止损与-18%硬性归零止损防止逻辑滞后+阴跌死扛；新增"三信号确认"客观校验流程防止确认偏误导致越亏越扛。


## 一、选题材标准（"四看"框架 + "第五看"滤网）

**核心原则：选择供给端刚性锁定 + 需求端稳定增长 + 短期内有强催化预期的行业。**

用"四看"筛选：

| 维度       | 标准                                     | 验证案例                             |
| ---------- | ---------------------------------------- | ------------------------------------ |
| **看供给** | 政策、配额、技术壁垒导致供给无法随意增加 | 三代制冷剂配额锁死；MDI双碳锁产能    |
| **看需求** | 下游需求刚性，且近期有新增长点           | 空调+汽车+冷链；AI算力驱动的材料需求 |
| **看价格** | 核心产品价格处于上涨通道或高位稳定       | R32长协价持续上涨；MDI年内多次提价   |
| **看催化** | 未来3-6个月有明确事件驱动                | Q3长协涨价落地；中期分红；旺季备货   |

**操作**：每周花15分钟追踪2-3个潜在板块的核心变量（价格、库存、开工率、政策动态），找到"四看"全部成立的交集。

### ⚠️ 补充规则——估值水位滤网（"第五看"）

**在四看全部成立后，必须额外校验该标的"过去12个月涨幅"。**

| 过去12个月涨幅     | 结论                       | 执行                                                         |
| ------------------ | -------------------------- | ------------------------------------------------------------ |
| **≤ 50%**          | 进入观察池，可启动选股流程 | 正常推进                                                     |
| **> 50% 且 ≤ 80%** | 高风险信号                 | 仅允许以**30%仓位上限**参与，且需PE<15倍+机构目标价仍有30%以上空间 |
| **> 80%**          | **直接放弃**               | 无论四看多完美，不建仓、不关注                               |

> **为什么要加这道滤网？** 四看全是基本面（供给/需求/价格/催化），唯独漏掉了"市场是否已充分定价"。再好的逻辑，买在珠穆朗玛峰顶，死扛也难回本。2021年新能源PE 50倍时四看全对，买进去就是山顶——这道滤网就是防止这种情况。


## 二、选股标准（五层筛子，估值容忍度放宽）

**核心原则：在景气行业中，选择市占率领先、业绩弹性大、估值相对合理、业务聚焦的公司。**

用"五层筛子"：

| 筛子         | 标准                                             | 实战校验                            |
| ------------ | ------------------------------------------------ | ----------------------------------- |
| **行业地位** | 市占率前三或细分龙头，拥有定价权                 | 万华MDI全球龙头；巨化制冷剂配额第一 |
| **业绩弹性** | 最近财报净利润增速 > 50%，且涨价能直接转化为利润 | 万华上半年净利+60%-70%              |
| **估值容忍** | 动态PE < 30倍，PEG < 1                           | 万华PE约15倍；巨化PE约13倍          |
| **业务聚焦** | 主营产品占营收比例高，涨价弹性大                 | 万华MDI/聚氨酯为主                  |
| **可跟踪性** | 只需跟踪1-2个高频数据                            | MDI价格、制冷剂长协价               |

**重要修订**：估值指标是"排除泡沫"的工具，不是"决定买卖"的核心依据。只要四看逻辑完整且未被市场充分定价，PE在15-25倍区间均为合理。如果因为PE高了10%就放弃一个四看全对的标的，那就是捡了芝麻丢了西瓜。


## 三、买入标准（中线逻辑下的仓位执行）

> **V2.0 修订**：一旦"四看"逻辑确认，下跌就是机会，而不是风险。在逻辑未被证伪之前，每一次回调都是加仓窗口，而不是减仓理由。

### 1. 战略建仓（中线逻辑确认后的主仓位）

当"四看"逻辑全部确认（且通过"第五看"估值水位滤网）后，不再等待"完美买点"：

| 条件                  | 标准                                         | 执行                                  |
| --------------------- | -------------------------------------------- | ------------------------------------- |
| 四看全对 + 第五看通过 | 供给+需求+价格+催化全部成立 + 12个月涨幅≤50% | 进入"可建仓"状态                      |
| 价格位置              | 从高点回撤15%-30%，或处于历史估值低位        | 测算目标空间与当前价位的赔率          |
| 仓位设定              | 确定性高（强催化明确）首次可**30%-50%**      | 一次性建立核心仓位，不再分批试探      |
| 加仓规则              | 逻辑未变的前提下，每下跌3%-5%加仓一次        | 越跌越买，直至达到单票仓位上限（70%） |
| 具体案例              | 万华在73-75元区间，四看全对，一次性建仓至60% | 即使后续跌到70元，逻辑不变则继续持有  |

**核心原则**：买的是"逻辑"，不是"最低点"。为逻辑付费是值得的，为等待最低点而踏空是不可接受的。

### 2. 战术做T（仅限已有底仓，短差操作）

在底仓已建立的前提下，可用不超过总仓位10%的资金做T，降低持仓成本：

| 条件     | 标准                           | 执行                            |
| -------- | ------------------------------ | ------------------------------- |
| 前提     | 已有足够的底仓（≥50%计划仓位） | 仅用额外资金做T，不涉及底仓     |
| 买入时机 | 日内或短期快速下跌至支撑位     | 挂单买入，反弹至压力位卖出      |
| 卖出时机 | 日内或短期快速反弹至压力位     | 卖出T仓，底仓不动               |
| 风险控制 | T仓严格设止损（-2% ~ -3%）     | 若T仓被套，坚决止损，不转为底仓 |

**重要提醒**：做T是"锦上添花"，不是"雪中送炭"。如果T仓做错了，果断止损，不要让它影响底仓的判断。


## 四、卖出/止盈标准

**核心原则：目标明确，分批止盈，让大部分仓位吃到主升浪。**

| 批次         | 止盈条件                                     | 卖出比例           | 实战案例                      |
| ------------ | -------------------------------------------- | ------------------ | ----------------------------- |
| **第一止盈** | 达到成本 +15%~20%                            | 卖出持仓的 **20%** | 万华从74涨至85-88元，卖20%    |
| **第二止盈** | 达到成本 +30%~40%                            | 再卖持仓的 **20%** | 万华从74涨至96-103元，再卖20% |
| **剩余仓位** | 逻辑未变则继续持有，目标看到机构一致预期上限 | **60%** 博更高收益 | 剩余仓位看110元以上           |

**特殊止盈**：若行业出现重大利空（如产品价格连续两周下跌、政策逆转），立即清仓，不恋战。

**重要修订**：不要因为"已经赚了10%"就急着卖。中线波段的利润空间是30%-50%，不是10%。过早卖出等于用中线逻辑建仓，却用短线思维离场。


## 五、止损标准（保护本金，永不改变）

**核心原则：宁可卖错，不可被深套。止损位一旦设定，盘中不修改。**

| 类型               | 标准                                                    | 实战应用                                                     |
| ------------------ | ------------------------------------------------------- | ------------------------------------------------------------ |
| **固定止损**       | 买入价的 **-10% ~ -12%**                                | 宽于V1.0的-8%，为正常波动留出空间                            |
| **逻辑止损**       | 核心逻辑被证伪（产品价格趋势下跌、业绩变脸、政策逆转）  | 无条件清仓，不论盈亏                                         |
| **移动止损**       | 股价上涨后，将止损上移至关键支撑位                      | 万华从74涨至85后，止损上移至75                               |
| **🆕 时间止损**     | 建仓后**60个交易日内**，若无任何催化事件推动股价涨幅>5% | 主动减仓至30%。时间成本必须计入，逻辑没兑现说明判断有误或市场不认 |
| **🆕 硬性归零止损** | 若浮亏达到**-18%**（无论逻辑多美）                      | **无条件减仓一半**（不是清仓）。这是"判断错误"的保险，保留下次翻盘的种子 |

**执行顺序**：固定止损（-10%~-12%）是最先触发的底线 → 若未触发但阴跌至-18%，触发硬性归零止损 → 60个交易日无催化触发时间止损 → 逻辑止损随时监控。

**重要修订**：V1.0的-8%止损在正常波动中容易被击穿（万华曾因73.20止损被打掉200股）。V2.0将固定止损放宽至-10%~-12%，给中线逻辑足够的容错空间。V2.1新增时间止损和-18%硬性归零止损，防止"逻辑滞后+阴跌死扛"的致命组合。


## 六、仓位管理（集中火力，敢于重仓）

**核心原则：小资金的优势是集中，不是分散。在看得懂的机会上，敢于下注。**

| 资金规模    | 单只股票最大仓位 | 首次建仓比例          | 加仓后最大比例 |
| ----------- | ---------------- | --------------------- | -------------- |
| 8.5万阶段   | **70%**          | 30%-50%（四看确认后） | **70%**        |
| 10-15万阶段 | **70%**          | 30%-50%               | **70%**        |
| 15万以上    | 60%              | 30%-40%               | 60%            |

**加仓条件**：
- 四看逻辑未变
- 价格回落到预设区间，或出现新的下跌机会
- 加仓后总仓位不超过上限

**仓位压力管理**：如果重仓后感到焦虑，不是因为"仓位重"，而是因为"逻辑还不够确定"。回到四看框架重新校验，如果逻辑成立，焦虑是没有必要的；如果逻辑不成立，减仓而不是硬扛。


## 七、交易频率与节奏

**核心原则：一年做4-5个中线波段，每个波段1-2只核心标的，空仓期不超过2个月。**

| 阶段    | 任务                              | 节奏               |
| ------- | --------------------------------- | ------------------ |
| 1-3月   | 布局年报预增 + 春季旺季品种       | 建仓→持有→逐步兑现 |
| 4-6月   | 主做一季报 + 夏季旺季（如制冷剂） | 建仓→持有→逐步兑现 |
| 7-9月   | 中报行情 + 秋季旺季               | 建仓→持有→逐步兑现 |
| 10-12月 | 三季报 + 跨年行情                 | 建仓→持有→逐步兑现 |


## 八、辅助策略：蓝筹底仓与打新配置

**目的**：在不影响主仓位的前提下，利用闲置资金配置高股息蓝筹股，获取打新额度和小额稳健收益。

### 1. 蓝筹底仓的择时信号

| 信号                         | 操作                     | 仓位            |
| ---------------------------- | ------------------------ | --------------- |
| 中证红利指数回撤超过 -10%    | 进入观察区间，可分批建仓 | 不超过总资金15% |
| 中证红利指数回撤超过 -15%    | 加仓至上限               | 总资金15%-20%   |
| 个股股息率 > 4% 且 PE < 15倍 | 纳入观察池               | —               |

**历史验证**：中证红利全收益指数近5年滚动持有1年正收益概率100%。当指数回撤超-10%时买入，持有1年平均收益率显著为正。

### 2. 优先配置方向

按优先级排序：

| 优先级 | 标的                    | 逻辑                         |
| ------ | ----------------------- | ---------------------------- |
| 1      | 红利ETF易方达（515180） | 一揽子高股息蓝筹，天然分散   |
| 2      | 兖矿能源（600188）      | 高股息+国企改革+煤炭价格稳定 |
| 3      | 中国神华（601088）      | 高股息+煤炭龙头+长协价锁死   |
| 4      | 招商银行（600036）      | 银行龙头+高股息+不良率稳定   |
| 5      | 长江电力（600900）      | 水电龙头+高分红+供给刚性     |

### 3. 与主仓位的优先级关系

| 顺序           | 资金用途                                     |
| -------------- | -------------------------------------------- |
| **第一优先级** | 万华等四看标的的主仓位（机会出现时优先配置） |
| **第二优先级** | 备足主仓标的的补仓资金（下跌时有子弹加仓）   |
| **第三优先级** | 闲置资金配置蓝筹底仓（打新额度+稳健收益）    |

**核心原则**：蓝筹底仓是"锦上添花"，不是"雪中送炭"。如果主仓位需要补仓资金，蓝筹底仓可随时卖出回笼资金。


## 九、持仓期间的客观信号校验（🆕 V2.1新增——最重要的一节）

**核心问题**：手册说"回去验四看"——但当浮亏15%时，你的大脑会疯狂找理由"证明逻辑还在"，这叫**确认偏误**。四看框架本身变成了情绪硬扛的工具，而不是客观判断的标准。

**解决方案**：建仓当日必须完成"三信号确认"流程，用客观数据打断主观幻想。

### "三信号确认"执行流程

**第一步（建仓当日）** ：写下该持仓的"三个必须发生的客观信号"，信号必须是：
- **可量化**（有具体数字，不是"景气度向好"这种模糊表述）
- **可验证**（每周六能查到数据，不是"未来会改善"这种无法证伪的）
- **与持仓逻辑直接相关**（不是大盘指数、不是宏观叙事）

**标准模板示例（以万华化学为例）** ：

| 信号编号 | 客观信号内容   | 数据来源        | 达标标准     |
| -------- | -------------- | --------------- | ------------ |
| 信号一   | MDI周度报价    | 生意社/百川盈孚 | ≥ 18000元/吨 |
| 信号二   | MDI装置开工率  | 行业周报        | ≥ 80%        |
| 信号三   | 中报净利润增速 | 公司公告        | ≥ 50%        |

**第二步（每周六核对）** ：

| 本周信号达成情况         | 结论         | 执行                                     |
| ------------------------ | ------------ | ---------------------------------------- |
| 三个信号**全部**发生     | 逻辑验证通过 | 正常持有，可评估加仓                     |
| **两个**信号发生         | 逻辑部分验证 | 谨慎持有，关注缺失信号的原因             |
| **仅一个或零个**信号发生 | 逻辑验证失败 | ⚠️ **下周观察**：若连续两周如此，触发减仓 |

**第三步（连续不达标执行）** ：

> **如果连续两周仅有一个或零个信号发生 → 强制减仓至30%**，直到信号重新出现三个中的至少两个，方可恢复仓位。

**为什么"三信号确认"是三个补丁里最强的？**

因为它把"回去验四看"从一句口号变成了**可执行的客观流程**。你不用再纠结"逻辑还在不在"这种主观问题——信号发生了就是发生了，没发生就是没发生。用客观数据打断主观幻想，这是防止确认偏误最有效的手段。


## 十、心态与纪律

> **V1.0 的核心缺陷**："只看收盘价，盘中不决策"是对的，但"不决策"不等于"不行动"。当价格到达预设区间时，该挂单就挂单，该加仓就加仓，而不是"等确认了再动手"。

### 九条铁律（V2.1修订）

1. **逻辑未变，跌了是机会**：四看确认后，下跌是更好的买入机会，不是恐慌的理由。
2. **计划内重仓，计划外空仓**：高确定性时敢于重仓（50%-70%），但绝不做临时单。
3. **不追求完美买点**：为逻辑付费是值得的，为等待最低点而踏空是不可接受的。
4. **不看日内波动**：90%的波动是噪音，只有逻辑和收盘价有意义。
5. **不频繁换股**：一年4-5个波段，每个波段1-2只核心标的，反复跟踪验证。
6. **不比较收益**：别人的涨停与你无关，只关注自己的曲线。
7. **接受波动，不轻易止损**：小资金进攻必然伴随更大回撤（20%以内正常），只要逻辑未变，不因短期浮亏而动摇。
8. **中线逻辑看中线**：不要因为短期下跌就怀疑四看逻辑，不要因为短期上涨就急于兑现。
9. **牢记目标**：8.5万到30万是两年任务，不是一个月。耐心比爆发力更重要，但耐心不等于不作为——在逻辑确认的位置，敢于下注。


## 十一、小资金进阶路线图

| 阶段       | 目标                   | 关键点                                                     |
| ---------- | ---------------------- | ---------------------------------------------------------- |
| **阶段一** | 8.5万 → 15万（第一年） | 选对行业，重仓吃主升，完成2-3个波段                        |
| **阶段二** | 15万 → 30万（第二年）  | 利用复利效应加速，单票仓位可至70%                          |
| **阶段三** | 30万以上（稳健版）     | 降低进攻性，单票仓位降至30%-40%，追求年化20%-30%可持续复利 |


## 附一：实战复盘——从三美到万华的教训凝练

### 三美股份（603379）——错过，但躲过了大跌

| 阶段   | 动作                             | 结果       | 教训                     |
| ------ | -------------------------------- | ---------- | ------------------------ |
| 选题材 | 四看全对，制冷剂配额锁死         | ✅ 逻辑正确 | —                        |
| 选股   | 三美制冷剂营收占比85%，弹性最大  | ✅ 选股正确 | —                        |
| 买入   | 等回踩60元，结果最低57元，未成交 | ❌ 踏空     | 为等最低点而错过合理买点 |
| 后续   | 三美从62涨至87元，又跌回57元     | ⚠️ 未参与   | 如果追高买入，会被套牢   |

**核心教训**：四看逻辑确认后，不要因为"想等更低价格"而错过合理买点。为逻辑付费是值得的，为等待最低点而踏空是不可接受的。

### 万华化学（600309）——验证中，执行层面改进

| 阶段  | V1.0执行                              | V2.0/V2.1改进                        |

## 附四：V2.1 核心补丁总结

| 补丁                                | 解决的问题                                 | 核心规则                                 | 触发执行        |

**本手册使用期限**：账户资金 ≤ 30 万期间
**切换条件**：账户首次达到 30 万，或连续 3 个月回撤超过 20%（说明进攻版不适合当前市场），立即切换回稳健版。

**记住：小资金做大的核心，不是赌，而是在看得懂的机会上敢于下注，并严守纪律。四看逻辑确认后，下跌不是风险，是机会。**
